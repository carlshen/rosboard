# ROS Bridge Install and Run Guide

0 ROS env support, and install ros-noetic-rospy-message-converter;

1 install redis;

2 install mysql;

3 import fy_init.sql for mysql db;

5 compile ZLMediaKit, and run ./MediaServer;

6 cd rosboard, and run ./run;
